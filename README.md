# Clase_5
Sistema de Registro Académico
Descripción

Este programa fue desarrollado en Python y permite realizar un registro académico básico de estudiantes. El sistema solicita información personal, notas, asistencia y conducta del estudiante para generar un reporte completo con el estado académico final.

Funcionalidades

El programa permite:

Registrar datos personales del estudiante.
Ingresar calificaciones de diferentes actividades.
Calcular el promedio general.
Mostrar la nota más alta y la más baja.
Verificar la asistencia mínima requerida.
Evaluar la conducta del estudiante.
Generar observaciones automáticas.
Agregar puntos extra por participación.
Mostrar el resultado final del estudiante.
Datos que solicita el sistema
Información personal
Nombre
Apellido
Edad
Curso
Paralelo
Notas
Primer parcial
Segundo parcial
Proyecto final
Examen final
Información adicional
Porcentaje de asistencia
Conducta
Participación extra
Requisitos

Para ejecutar el programa se necesita:

Tener instalado Python 3.
Un editor como:
Visual Studio Code
PyCharm
IDLE
Dev-C++
Ejecución del programa
Guardar el archivo con extensión .py
Abrir la terminal o consola.
Ejecutar el siguiente comando:
python nombre_archivo.py
